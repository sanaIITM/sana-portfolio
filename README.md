# Sana Bint Salim — Portfolio

A responsive React portfolio with separate **Professional** and **Personal** spaces.

## Local preview

The site loads React and React DOM as browser ES modules. Open `index.html` with a local static server, for example:

```bash
npx serve .
```

## Build

```bash
npm ci
npm run build
```

The build writes `dist/`, ready for Render Static Sites. Render build command: `npm ci && npm run build`; publish directory: `dist`.

Project descriptions, skills, education and interests are maintained in `index.html`. The portfolio intentionally does not use a personal photograph.
